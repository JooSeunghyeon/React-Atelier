# React number 입력의 빈 값은 Number('')로 0이 된다

이 예제는 type="number" 입력 필드의 onChange에서 빈 입력이 어떤 값으로 상태에 저장되는지 확인한다.

입력란을 모두 지우면 event.target.value는 빈 문자열이다. 이 값을 Number()로 감싸면 Number('')는 0이 된다. 그래서 상태에는 빈 문자열이 아니라 0이 들어간다.

코드에서 확인하는 것은 세 가지다.

- 빈 입력에서 raw 값과 변환 결과를 함께 출력한다.
- 공백 한 칸 입력은 Number(' ')도 0이 되는지 본다.
- 숫자 입력은 그대로 변환되는지 본다.

브라우저 콘솔에서 로그를 보면서 입력란을 지우고 다시 입력해 본다.
